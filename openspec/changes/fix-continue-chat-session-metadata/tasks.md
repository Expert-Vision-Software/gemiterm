- [x] 2.1 In `src/services/gemini-client-wrapper.ts`, add a `chatMetadata: ChatMetadataStorage` field initialized in the existing constructor (or via a 5th constructor arg `chatMetadata?: ChatMetadataStorage` defaulting to `new ChatMetadataStorage(logger)`). - [x] 2.2 Add the private helper `extractChatMetadata(metadata: (string | null)[] | undefined): ChatMetadata | null` (top of file, alongside `persistRefreshedCookies`). It MUST return `null` when `metadata` is undefined or when both `metadata[1]?.rid` and `metadata[2]?.rcid` are falsy (empty/missing). Otherwise return `{ rid: metadata[1]!, rcid: metadata[2]!, ctx: metadata[9] ?? null }`.
- [x] 2.3 Refactor `GeminiClientService.sendMessage(conversationId, message)` so it:
  - Looks up stored metadata via `this.chatMetadata.lookup(this.profileName, conversationId)` (only when `this.profileName` is set — the factory instance has no profile).
  - When found: constructs `session = this.client!.newChat({ metadata: [...10-slot array with rid/rcid from stored metadata... ] })`.
  - When not found: falls back to the existing `client.newChat() + session.cid = conversationId` path with a single `this.logger.debug(...)` log line that names the profile and the cid.
  - After the inner `generateContent` resolves successfully: extract `output.metadata` via `extractChatMetadata`, and if non-null, call `this.chatMetadata.save(this.profileName, conversationId, captured)`.
  - The existing `persistRefreshedCookies` call and the existing `translateError` / rethrow path stay unchanged.
- [x] 2.4 Refactor `GeminiClientService.startNewChat(message)` so it captures metadata after the inner `generateContent` resolves: extract `output.metadata`, derive `conversationId = output.cid`, call `extractChatMetadata`, and (when non-null) persist via `this.chatMetadata.save(this.profileName, conversationId, captured)`. The existing return shape `{ response, conversationId }` stays the same; we just persist metadata on the side. Persistence is gated on `this.profileName` being set (factory-client case is a no-op).
- [x] 2.5 Confirm the wrapper's constructor signature stays backward-compatible: the test setup at `tests/services/gemini-client-wrapper.test.ts` constructs `new GeminiClientService({ secure1psid }, logger, cookieStorageService, profileName, deps)`.
